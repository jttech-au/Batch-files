install.esd to install.wim
dism /get-wiminfo /wimfile:install.esd
Index : 6
Name : Windows 10 Pro
Description : Windows 10 Pro
Size : 14,604,257,035 bytes
dism /export-image /SourceImageFile:install.esd /SourceIndex:6 /DestinationImageFile:install.wim /Compress:max /CheckIntegrity

Add Drivers to install.wim
dism /get-wiminfo /wimfile:install.wim
dism /mount-wim /wimfile:install.wim /index:1 /mountdir:temp
dism /image:temp /add-driver:Drivers /recurse
dism /unmount-wim /mountdir:temp /commit

Add Drivers to boot.wim (If required)
dism /mount-wim /wimfile:boot.wim /index:2 /mountdir:temp
dism /image:temp /add-driver:"E:\Dell\Intel Rapid Storage Technology Driver and Management Console\Drivers\Production\Windows10-x64" /recurse
dism /unmount-wim /mountdir:temp /commit

Add Packages
# Download Cumulative Updates, https://support.microsoft.com/en-ca/help/4099479/windows-10-update-history
dism /mount-wim /wimfile:install.wim /index:1 /mountdir:temp
dism /image:temp /add-package /packagepath:e:\windows10.0-kb4469342-x64_7290815610ac4c3d657eb5ed6e4e92421fa8c29a.msu
dism /unmount-wim /mountdir:temp /commit

Split WIM File
For UEFI Boot fat32
dism /split-image /imagefile:install.wim /SWMFile:install.swm /filesize:2048
Delete or move install.wim from Sources folder once finished.
